# pokemon-battle-predictor-neural-network

A simple Pokémon Battle Predictor built using Python, NumPy, and TensorFlow/Keras. It uses a feedforward neural network to predict battle outcomes based on Attack, Defense, Speed, and Opponent Power.

The project explores fundamental deep learning concepts, including data preprocessing, normalization, neural network architecture, binary classification, model training, and performance evaluation.

This is an ongoing learning project that I plan to expand with further experiments, model improvements, and additional ML concepts as I progress.
